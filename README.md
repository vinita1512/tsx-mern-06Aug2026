# Star Wars Character App

A responsive React + TypeScript application that displays Star Wars characters using SWAPI.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Axios

## Features

- Character List
- Pagination
- Character Details Modal
- Homeworld Information
- Species-based Card Color
- Responsive UI

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
